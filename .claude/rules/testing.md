# Правила фабрики: тести

- Unit/integration — Vitest, E2E — Playwright (лише критичні user flows).
- Назва тесту містить Task ID і AC: `"DEV-001 AC-2: фільтрує задачі за статусом"` — gate перевіряє, що кожен AC з плану покритий.
- Не видаляй тести, не додавай `.skip`/`.only`, не послаблюй assertions заради зеленого результату.
- Тест має падати на зламаному коді: перевіряй поведінку, а не реалізацію.
- Без мережі й реальних API-ключів у тестах: LLM-виклики — через mock-режим.
