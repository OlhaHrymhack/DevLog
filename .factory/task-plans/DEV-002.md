# DEV-002 — UI Kit і токени

## Мета
Усі візуальні примітиви з прототипу як React-компоненти на токенах + сторінка `/ui-kit` (лише dev). Наступні задачі (DEV-005…012) лише компонують готове, нових кольорів поза токенами немає.

## Контекст
- Джерело правди: `docs/vault/specs/DEV-002.md` (AC-1…AC-8 без зміни нумерації), `docs/design/DESIGN.md` (§2 токени, §6 карта компонентів, §7 a11y), `docs/design/tokens.css`, `docs/design/prototype.html` (CSS 53–366, хелпери 375–439, домен 441–563 — прочитано повністю; решта прототипу — екрани й агенти — не входить у DEV-002).
- Є з DEV-001: Next 16 + Tailwind v4 (loader `@tailwindcss/turbopack`, D-020), `components.json` з aliases (`@/shared/ui`, `@/shared/lib/cn`, `@/shared/lib/hooks`), `cn`, boundaries-ESLint (`no-unknown-files`), Vitest (node + jsdom), Playwright (3 viewport-и, порт 3100, `AI_MODE=demo`). `globals.css` поки лише `@import "tailwindcss"`.
- DEV-003 очікує `TaskStatusSchema`/`TaskPrioritySchema` у `entities/task/model/schemas.ts` — створюємо лише їх; повні `TaskSchema` і т. д. — DEV-003.
- Slices — camelCase (D-014): `features/themeToggle`, `entities/agentRun` (DESIGN §6 пише kebab — спека має пріоритет).

## Acceptance criteria (з специфікації, нумерація збережена)
- AC-1: Токени обох тем збігаються з `tokens.css`.
- AC-2: `getHeat(task, now)` повертає правильний рівень для всіх 7 випадків і меж.
- AC-3: `plural`, `ageLabel`, `formatDate` (+ `daysBetween`) коректні.
- AC-4: Тема: dark за замовчуванням, зберігається в `localStorage["devlog-theme"]`, без мерехтіння.
- AC-5: Компоненти мають усі варіанти і доступні (aria-label, sr-текст, tooltip по фокусу).
- AC-6: `/ui-kit` показує всі компоненти в обох темах; у production — 404 (`notFound()`).
- AC-7: Адаптив і контраст: 375 / 768 / 1280, обидві теми, без горизонтального скролу, AA, `TaskRow` → картка < 1024.
- AC-8: `prefers-reduced-motion` вимикає анімації.

## Рішення (технічні, без зміни поведінки)
1. **Tailwind v4 замість `tailwind.config.ts` з DESIGN §2.6:** мапінг токенів — `@theme inline` у `globals.css` (v4 конфігурується через CSS). Кольори/радіуси/шрифти/тривалості — ті самі імена, що в §2.6.
2. **`globals.css`** = токени з `tokens.css` **дослівно** (щоб AC-1 порівнював набір змінних і значень) + `@theme inline` + змінні shadcn (`--background`, `--primary`, `--ring`, …) як посилання на наші токени + базові стилі прототипу (`:focus-visible`, `.sr-only` — вже в Tailwind) + `@keyframes` + глобальне `prefers-reduced-motion` (рядок 366 прототипу).
3. **Шрифти:** Inter 400/500/600/700 (за специфікацією; DESIGN §2.2 каже 400/500/600 — спека новіша) і JetBrains Mono 500 через `next/font/google`, змінні `--font-sans` / `--font-mono`. Ризик: збірка потребує мережі (CI має).
4. **Тема без мерехтіння:** `data-theme="dark"` на `<html>` з сервера + інлайн-скрипт у `<head>` (читає `localStorage["devlog-theme"]`, ставить `data-theme` до гідратації) + `suppressHydrationWarning`. `features/themeToggle` — client-компонент (`useSyncExternalStore` / ефект), `aria-label` «Увімкнути світлу тему» / «Увімкнути темну тему».
5. **shadcn** додаємо через CLI (`npx shadcn@latest add …`) у `src/shared/ui/` без правок форми. Виняток: `sonner` не має залежати від `next-themes` (теми в нас свої) — прибираємо цей імпорт і передаємо `theme` пропсом; відхилення фіксуємо в decisions. Якщо згенеровані файли порушують ESLint (`as`, `any`) — оверрайд для `src/shared/ui/**` в `eslint.config.mjs` (не правимо згенероване).
6. **Tooltip на тач:** HeatBadge — shadcn `Tooltip` у контрольованому режимі: відкривається по hover/focus і перемикається тапом (`onClick`), без нового компонента Popover.
7. **Тести компонентів:** додаємо `@testing-library/react` (+ `@testing-library/dom`, peer) у devDependencies — спека AC-5 вимагає Testing Library, DEV-001 їх свідомо не ставив до цієї задачі. `jest-dom` не додаємо (звичайні assertions).
8. **Час:** `now` — параметр (`getHeat(task, now)`, `ageLabel(ts, now)`); `TaskRow`/`/ui-kit` отримують `now` пропсом із фіксованого значення — без гідратаційних розбіжностей. Дати — ISO-рядки; `formatDate` форматує в локальній зоні.
9. **Типи:** `TaskStatus`, `TaskPriority` — `z.infer` з `schemas.ts`; пропси `TaskRow`/`getHeat` приймають мінімальний `Pick` потрібних полів, повна `Task` з'явиться в DEV-003.
10. **`/ui-kit`:** `src/app/ui-kit/page.tsx` (тонкий, `notFound()` коли `NODE_ENV === "production"`) → `views/uiKit`. Page — `export default` (дозволено в `src/app`).

## Ризики
- **shadcn CLI / мережа:** якщо `shadcn add` недоступний — компоненти пишемо вручну за шаблоном new-york і повідомляємо.
- **Google Fonts:** `next build` без мережі падає; CI має мережу. Локально `next dev` лише попередить.
- **Згенеровані shadcn-файли проти ESLint-стайлгайду:** оверрайд для `src/shared/ui/**`, форму не змінюємо (стайл-гайд: «лишаються в оригінальній формі»).
- **Мерехтіння теми** перевіряється лише в E2E без гідратації — не доводить відсутність flash у реальному браузері; візуально — QA.
- **Tooltip на тач:** тап-перемикач у контрольованому режимі; ручна перевірка на 375 — QA.
- **Обсяг:** найбільша за кількістю файлів задача на цей момент; verify і рев'ю повільніші (opus-рев'ю не потрібне — security/integrations = 0).
