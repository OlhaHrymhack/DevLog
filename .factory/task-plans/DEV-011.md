# DEV-011 — Агент C «Статус-апдейт»

## Мета

Агент пише коротке Slack-повідомлення про стан задачі з її даних (підзадачі, нотатки), сам обирає тон за контекстом або бере тон від користувача, не згадує фактів, яких немає в даних, і нічого не надсилає — лише «Скопіювати». Закриває R-08, R-05, R-18; TC-45…51.

Tier balanced (за специфікацією і за балами). Реалізація в головній сесії (Sonnet), рев'ю й security — opus. Специфікація — `docs/vault/specs/DEV-011.md`; прототип — `docs/design/prototype.html` (`TONES`, `autoTone`, `buildUpdate`, `slackToHtml`, `runStatusUpdate`, `typeOut`, `renderAgentC` 805–909; `c-tone`, `c-copy` 1264–1265; `copyText` 1208–1211).

## Рішення

1. `StatusUpdate` = `{ tone, text, mentions: { subtaskIds, noteIds }, thin }` (усі поля required; `thin` — boolean замість optional для strict-режиму OpenAI).
2. Перевірка фактів (`factCheck`): `mentions` існують у цій задачі; посилання `PR #n`, `#n`, URL у тексті є в описі/нотатках; `manager` без емодзі-жартів; `short` ≤ 200 символів; назви підзадач у тексті лише наявні.
3. Без AI: `autoTone` — чиста функція (done → team; heat ≥ «гаряча» або є дедлайн → manager; інакше team) з поясненням; fallback — шаблон `short` з тих самих даних.
4. Прев'ю тексту рендериться як React-вузли: `*bold*` → `<strong>`, решта — текст. Нотатка з `<img onerror>` лишається текстом (AC-8).
5. Копіювання — лише `navigator.clipboard.writeText`; агент мережею нічого не надсилає (AC-6).
6. Тестові дані E2E: власні задачі через API там, де не потрібен вік (heat); для heat/дедлайну — seed-задачі t1, t9, t6, t3 лише читаються.

## Acceptance criteria (зі специфікації, нумерація збережена)

- **AC-1** Апдейт у стилі Slack з даних задачі. [U] mock на t9 (`team`) → «*Rate limiting для /api/agents*: апдейт», «Готово: …», «Нотатка: …», «Далі: …» (TC-45).
- **AC-2** Авто-тон. [U] `autoTone`: t1 → manager; t2 (дедлайн) → manager; t9 → team; t6 (done) → team (TC-46). [E] t1 → «Згенерувати» → крок «Тон: для менеджера», чіп «Авто → для менеджера», у тексті «Ризик: чекаємо на ревʼю…».
- **AC-3** Ручний тон. [E] після результату «Коротко» → перезапуск, текст в один рядок; серйозний режим → чіпа «З гумором» немає; [U] `humor` + `serious` → 400 (TC-47).
- **AC-4** Мало даних. [U] t3 (0 підзадач, 0 нотаток) → `thin: true`, без вигаданих «Готово: …»; [E] alert «Даних мало…» (TC-48).
- **AC-5** Перевірка фактів. [U] «PR #999» при нотатці з «PR #318» → порушення; «PR #318» → ок; чужі `subtaskIds` → порушення (TC-49, TC-51). [E] «Зламати відповідь агента» → крок 4 «Факти не підтверджено», alert, шаблон «Коротко».
- **AC-6** Копіювання, нічого не надсилається. [E] «Скопіювати» → буфер = текст, тост; у мережі лише `/api/agents/status-update` (TC-50).
- **AC-7** Друк і доступність. [E] під час друку «Скопіювати» disabled; `reducedMotion: reduce` → текст одразу повністю; текст у `aria-live="polite"`.
- **AC-8** XSS-безпека прев'ю. [U] нотатка `<img src=x onerror=alert(1)>` → у SlackPreview як текст.
