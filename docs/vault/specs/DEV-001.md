# DEV-001 — Каркас і tooling

**Tier:** balanced · **Залежить:** — · **Розблоковує:** усі · **Агенти:** стандарт + 🔒 security (env, API-ключ)
**Покриття ТЗ:** R-10 (Next.js + route handlers), R-12 (`npm install && npm run dev`), R-13 (`.env.example`) · TC-60, TC-61, TC-62 з [[product]]

## Мета
Порожній, але повністю робочий застосунок: усі команди зелені, межі архітектури перевіряються лінтером, конфіг середовища валідується. Після цієї задачі будь-яку фічу можна додавати без налаштувань.

## Скоуп
**Входить:** Next.js App Router + TS strict; Tailwind + shadcn init (без компонентів — вони в DEV-002); Vitest; Playwright; pino; Zod-конфіг env; ESLint зі стайл-гайдом; `.env.example`; npm-скрипти; `prepare` → `.githooks`; мінімальна сторінка-заглушка і `GET /api/health`.
**Не входить:** токени й компоненти (DEV-002), БД (DEV-003), будь-яка бізнес-логіка.

## Реалізація
1. `create-next-app` (App Router, TS, ESLint, Tailwind, `src/`, alias `@/*`), npm. `tsconfig`: `strict`, `noUncheckedIndexedAccess`.
2. Структура шарів з `.gitkeep`/`index.ts`: `src/{app,views,widgets,features,entities,shared/{ui,lib,config,api},server}`.
3. `src/shared/config/env.ts` — Zod-схема серверного env:
   - `ANTHROPIC_API_KEY` — optional string; `ANTHROPIC_MODEL` — default `claude-opus-5-5`; `DATABASE_URL` — default `file:./data/devlog.db`; `LOG_LEVEL` — enum, default `info`; `AI_MODE` — optional `live | demo` (примусово).
   - Похідне `aiMode`: `AI_MODE` якщо задано, інакше `live` при наявному ключі, `demo` без нього.
   - Невалідний env → помилка на старті з назвою змінної, **без значення**.
   - Модуль імпортує `server-only`, щоб ключ не потрапив у клієнтський бандл.
   - Клієнту віддається лише `aiMode` (через серверний компонент / `GET /api/health`).
4. `src/server/logger.ts` — pino; `redact` для `*.apiKey`, `headers.authorization`, `ANTHROPIC_API_KEY`; dev — `pino-pretty`.
5. `.env.example` — усі змінні з п.3, без значень, з коментарем до кожної.
6. ESLint (flat config):
   - `func-style: declaration`; заборона `export default` поза `src/app/**` і конфіг-файлами;
   - `eslint-plugin-boundaries`: напрямок `app → views → widgets → features → entities → shared`, `server` імпортується лише з `src/app/api/**` і `src/server/**`; сусідні slices одного шару — заборона;
   - заборона глибоких імпортів у slice (лише через `index.ts`);
   - `no-console` (error), `@typescript-eslint/no-explicit-any` (error), `consistent-type-assertions` (`as` лише `as const`).
7. Скрипти `package.json`: `dev`, `build`, `start`, `lint`, `typecheck` (`tsc --noEmit`), `test` (`vitest run`), `test:e2e` (`playwright test`), `prepare` (`git config core.hooksPath .githooks`, без падіння, якщо не git).
8. Vitest: `environment` node за замовчуванням, `jsdom` для `*.test.tsx`; Playwright: `webServer` = `npm run dev` з `AI_MODE=demo`, проєкти 375 / 768 / 1280.
9. `src/app/page.tsx` — заглушка «DevLog»; `src/app/api/health/route.ts` → `{ status: "ok", aiMode }`.

## Acceptance criteria і тест-кейси
- **AC-1** Clean clone → `npm install && npm run dev` без `.env` стартує; `/` віддає 200.
  - [M] clean clone у тимчасову теку; [E] `GET /` → 200, `GET /api/health` → `{status:"ok", aiMode:"demo"}`.
- **AC-2** `typecheck`, `lint`, `test`, `test:e2e` зелені на чистому каркасі.
  - [M] прогін усіх 4 команд; evidence у `factory verify`.
- **AC-3** `aiMode` визначається правильно.
  - [U] без ключа → `demo`; з ключем → `live`; `AI_MODE=demo` з ключем → `demo`; `AI_MODE=foo` → помилка.
- **AC-4** Невалідний env дає зрозумілу помилку без значень секретів.
  - [U] `LOG_LEVEL=loud` → повідомлення містить `LOG_LEVEL`; текст помилки не містить значення ключа.
- **AC-5** Ключ не потрапляє в клієнт і логи.
  - [U] logger з `redact`: лог об'єкта з `apiKey` → `[Redacted]`; [M] `npm run build` + пошук ключа-маркера в `.next/static` → 0 збігів.
- **AC-6** ESLint ловить порушення стайл-гайду.
  - [U] фікстури (поза `src`, напр. `eslint-fixtures/`) прогоном ESLint API: `const X = () => …` компонент → error; `export default` у `features/` → error; імпорт `widgets` з `entities` → error; імпорт `src/server` з `features` → error; `console.log` → error.
- **AC-7** `.env.example` містить усі змінні схеми.
  - [U] парсинг `.env.example` і порівняння з ключами Zod-схеми; усі значення порожні.
