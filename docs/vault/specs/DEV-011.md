# DEV-011 — Агент C «Статус-апдейт»

**Tier:** balanced · **Залежить:** DEV-007, DEV-008 · **Агенти:** стандарт + 🔒 + 🎨 + E2E
**Покриття ТЗ:** R-08 («короткий асинхронний апдейт у стилі Slack з задачі, підзадач або нотаток; тон відповідає контексту»), R-05, R-18 · TC-45…51 з [[product]]

## Мета
Агент пише коротке Slack-повідомлення про стан задачі, сам обирає тон за контекстом (або користувач задає вручну) і не згадує фактів, яких немає в даних. Нічого не надсилає — лише «Скопіювати».

## Референс у прототипі
`TONES`, `autoTone`, `buildUpdate`, `slackToHtml`, `runStatusUpdate`, `typeOut`, `renderAgentC` (805–909); `c-tone`, `c-copy` (1264–1265); `copyText` (1208–1211).

## Агент (сервер, `src/server/agents/statusUpdate/`)
- **Вхід:** `{ taskId, tone: "auto" | "team" | "manager" | "short" | "humor", serious?, debug? }`. `humor` при `serious: true` → 400.
- **Tools (read-only):**
  - `get_task_context(id)` → задача, підзадачі (done / open), нотатки (текст, дата), `heat`, `staleDays`, `dueAt`;
  - `suggest_tone(id)` → `autoTone`: done → `team`; heat rank ≥ 2 (гаряча, палає, тривога) **або є дедлайн** → `manager`; інакше `team`; + пояснення («є ризик або дедлайн, тож пишу для менеджера» / «звичайний прогрес, пишу для команди»).
- **Кроки для UI:** «Зібрати задачу, підзадачі й нотатки» (detail «2 підзадачі · 1 нотатка») → «Визначити контекст і тон» («Тон: для менеджера», detail з поясненням або «вибрано вручну») → «Написати чернетку» → «Перевірити факти» («Згадано лише наявні підзадачі й нотатки»).
- **`submit_result` = `StatusUpdate`:** `{ tone: "team"|"manager"|"short"|"humor", text: string /* 20–800, Slack-markdown *bold* */, mentions: { subtaskIds: string[]; noteIds: string[] } }`.
- **factCheck:** усі `mentions` існують у цій задачі; у тексті немає посилань `PR #\d+`, `#\d+`, URL, яких немає в нотатках / описі; немає назв підзадач, яких немає; для `manager` — без емодзі-жартів; довжина: `short` ≤ 200 символів.
- **Mock-сценарій:** `get_task_context` → `suggest_tone` (якщо `auto`) → текст за `buildUpdate` прототипу для кожного тону:
  - `team`: «*<назва>*: апдейт», «Готово: …», «Нотатка: <остання>», «Далі: …», «Поки без помітного прогресу, беру в роботу.», для done «Задачу закрито 🎉»;
  - `manager`: «*<назва>*», «Статус: в роботі, прогрес 2 з 4 підзадач.», «Наступний крок: …», «Дедлайн: <дата>.», «Ризик: чекаємо на ревʼю, це блокує реліз.» / «Ризик: задача N днів без змін, потрібне рішення щодо пріоритету.»;
  - `short`: «*<назва>*: в роботі, 1/3 підзадач. Далі: ….»;
  - `humor`: «🚒 *<назва>*: новини з фронту», «✅ Вже зроблено: …», «🕵️ <нотатка>», «👀 Далі: …», «🫠 Прогресу поки нуль, але настрій бойовий.», «🌶️ Задача висить N днів. Стабільність, яку ми заслужили.»
- **Мало даних:** 0 підзадач і 0 нотаток → прапорець `thin: true` у результаті (UI-підказка), текст не вигадує прогрес.
- **Fallback:** шаблон `short` з тих самих даних.
- **Хибний кейс (fault injection):** чернетка згадує «PR #999», якого немає в нотатках → factCheck відхиляє → повтор теж → fallback. Крок 4 — `fail` «Факти не підтверджено», detail «У тексті згадано PR #999, якого немає в нотатках».

## UI (`widgets/statusUpdatePanel`, `features/generateStatusUpdate`)
Панель «Статус-апдейт» (MessageSquare, тег «Агент C»), права колонка деталей / вкладка «Апдейт».
- **ToneSelector** — чіпи `aria-pressed`: «Авто» (після результату — «Авто → для менеджера»), «Для команди», «Для менеджера», «Коротко», «З гумором» (прихований у серйозному режимі). У idle — лише вибір; після результату — зміна тону перезапускає агента.
- **idle:** «Агент складе коротке повідомлення у стилі Slack із задачі, підзадач і нотаток. Тон підбере за контекстом: є ризик чи дедлайн, отже пише для менеджера.» + чіпи + «Згенерувати апдейт».
- **running:** прогрес, кроки, «Зупинити».
- **result / fallback:** кроки; (fallback — alert «**Чернетку агента відхилено:** вона згадувала неіснуючий PR. Нижче короткий шаблонний апдейт без AI.»); якщо `thin` — alert-info «Даних мало: немає підзадач і нотаток. Додайте нотатку, і апдейт буде точнішим.»; чіпи; **SlackPreview** — бульбашка з лого `dl`, «#platform-team», «чернетка», текст з `*bold*` → `<b>` (через безпечний рендер, без `dangerouslySetInnerHTML` сирого тексту); друк по 3 символи / 14 мс з кареткою (без анімації при `prefers-reduced-motion`); «Скопіювати» disabled під час друку; іконка «Перегенерувати»; дрібно «Агент нічого не надсилає сам: скопіюйте й вставте в Slack.»; «Відхилити» → тост, idle.
- **Скопіювати** → `navigator.clipboard.writeText(text)` → тост «📋 Скопійовано. Тепер вдай, що писав сам» / «Апдейт скопійовано»; помилка буфера → «Не вдалося скопіювати. Виділіть текст вручну».

## Acceptance criteria і тест-кейси
- **AC-1** Апдейт у стилі Slack з даних задачі.
  - [U] mock на t9 (`team`) → «*Rate limiting для /api/agents*: апдейт», «Готово: вибрати алгоритм…», «Нотатка: Token bucket…», «Далі: middleware…, повертати 429…» (TC-45).
- **AC-2** Авто-тон.
  - [U] `autoTone`: t1 (hot) → manager; t2 (дедлайн) → manager; t9 (fresh, без дедлайну) → team; t6 (done) → team (TC-46).
  - [E] t1 → «Згенерувати» → крок «Тон: для менеджера», чіп «Авто → для менеджера», у тексті «Ризик: чекаємо на ревʼю…».
- **AC-3** Ручний тон.
  - [E] після результату «Коротко» → перезапуск, текст в один рядок; серйозний режим → чіпа «З гумором» немає; [U] `humor` + `serious` → 400 (TC-47).
- **AC-4** Мало даних.
  - [U] t3 (0 підзадач, 0 нотаток) → `thin: true`, текст без вигаданих «Готово: …»; [E] alert «Даних мало…» (TC-48).
- **AC-5** Перевірка фактів.
  - [U] factCheck: текст з «PR #999» при нотатці з «PR #318» → порушення; «PR #318» → ок; `subtaskIds` чужої задачі → порушення (TC-49, TC-51).
  - [E] dev-панель «Зламати» → крок 4 з X «Факти не підтверджено», alert, шаблон «Коротко».
- **AC-6** Копіювання, нічого не надсилається.
  - [E] (з дозволом clipboard у Playwright) «Скопіювати» → буфер = текст, тост; у мережі немає запитів окрім `/api/agents/status-update` (TC-50).
- **AC-7** Друк і доступність.
  - [E] під час друку «Скопіювати» disabled; `reducedMotion: reduce` → текст одразу повністю; текст у `aria-live="polite"`.
- **AC-8** XSS-безпека прев'ю.
  - [U] нотатка `<img src=x onerror=alert(1)>` → у SlackPreview відрендерено як текст.
