# DEV-002 — UI Kit і токени

**Tier:** balanced · **Залежить:** DEV-001 · **Розблоковує:** DEV-005…012 · **Агенти:** стандарт + 🎨 (`/design-review`, обидві теми, 375 / 768 / 1280)
**Покриття ТЗ:** R-19 (UI/UX), R-14 (UI scaffolded агентом) · TC-71, TC-73 з [[product]]

## Мета
Усі візуальні примітиви з прототипу як React-компоненти на токенах, зібрані на сторінці `/ui-kit`. Фічі далі лише компонують готове.

## Референс у прототипі
CSS-токени — `prototype.html` рядки 10–52 (= `docs/design/tokens.css`); кнопки 68–85; бейджі 166–175; heat 177–188; agent panel + кроки + прогрес 190–239; форми 286–296; оверлеї 298–324; стани (skeleton, empty) 326–331; toasts 333–342; анімації 344–366. Рендерери: `statusBadge`, `prioLabel`, `heatButton`, `stepsHtml`, `progressHtml`, `agentPanel` (рядки 528–563).

## Скоуп
**Входить:** токени, тема, шрифти, shadcn-компоненти, власні компоненти нижче, `getHeat`, сторінка `/ui-kit`.
**Не входить:** дані з API, бізнес-логіка, агенти.

## Реалізація
1. **Токени:** `docs/design/tokens.css` → `src/app/globals.css` (`:root`, `[data-theme="dark"]`, `[data-theme="light"]`). Tailwind theme мапить кольори/радіуси/відступи/тривалості на CSS-змінні (DESIGN §2.6); змінні shadcn (`--background`, `--primary`, `--ring` …) посилаються на наші токени. **Нових кольорів поза токенами немає.**
2. **Шрифти:** Inter (400/500/600/700) і JetBrains Mono (500) через `next/font/google`, змінні `--font-sans`/`--font-mono`.
3. **Тема:** `features/themeToggle` — кнопка-іконка (Sun у темній, Moon у світлій), `aria-label` «Увімкнути світлу тему» / «Увімкнути темну тему»; dark за замовчуванням; збереження в `localStorage["devlog-theme"]`; інлайн-скрипт у `layout.tsx` ставить `data-theme` до гідратації (без мерехтіння).
4. **shadcn** (`src/shared/ui/`, без змін форми): button, badge, card, dialog, sheet, input, textarea, select, checkbox, switch, tabs, tooltip, toggle-group, skeleton, progress, alert, sonner.
5. **Власні компоненти** (папка PascalCase, `index.tsx` + `types.ts` + `styles.ts` з cva):
   - `shared/ui/Button` — обгортка: `variant` primary · ghost · danger · danger-ghost · ai; `size` sm · md · icon; `:active` scale .97; disabled opacity .45.
   - `shared/ui/EmptyState` — `tone` neutral · humor · error; велика емодзі (float-анімація), заголовок, текст, дія.
   - `shared/ui/ResponsiveDialog` — Dialog ≥ 768, bottom sheet < 768 зі sticky діями; фокус-пастка, Esc, повернення фокусу.
   - `entities/task/ui/StatusBadge` — todo (кільце), in-progress (синя точка з пульсом), done (іконка Check); підписи «До роботи / В роботі / Готово».
   - `entities/task/ui/PriorityLabel` — high ChevronsUp «Високий», medium Minus «Середній», low ChevronDown «Низький».
   - `entities/task/ui/HeatBadge` — кнопка з емодзі, tooltip (назва, розшифровка, жарт якщо не серйозний режим); fire — мерехтіння, alarm — сирена; `aria-label` «Температура: <назва>. <розшифровка>»; prop `always` (показувати й рівні з `show:false`).
   - `entities/task/ui/TaskRow` — один компонент: рядок таблиці ≥ 1024, картка < 1024 (сітка з прототипу 154–164); пропси `task`, `focusRank?`, `onEdit`, `onDelete`; done — закреслена назва; alarm — підсвічений фон.
   - `entities/agentRun/ui/AgentPanel` — `title`, `icon`, `tag`, `collapsible` (< 1024 згортається, показує `summary`), `running` (пульс рамки), `demo`.
   - `entities/agentRun/ui/AgentStepList` — pending (пунктирне коло) · run (спінер) · done (Check) · fail (X), `detail` під кроком, `aria-live="polite"`, sr-текст стану.
   - `entities/agentRun/ui/AgentProgress` — `role="progressbar"`, % = done / усі кроки.
   - `entities/agentRun/ui/AgentFallbackAlert` — червоний alert `role="alert"` із заголовком і текстом.
   - `entities/agentRun/ui/AgentTag` — «✦ Агент X» або жовтий «Демо · Агент X».
6. **Домен температури:** `entities/task/model/heatLevels.ts` (7 рівнів з прототипу 450–458: emoji, name, rule, meaning, joke, show, rank) і `getHeat(task, now)` (460–472). Порядок перевірок: done → alarm (dueAt − now < 24 год) → low → calm → high 7+/5+/3+ → medium 3+ → fresh.
7. **shared/lib:** `cn`, `plural(n, one, few, many)` (укр.), `formatDate` («21 листопада 2026, 14:05»), `daysBetween(ts, now)`, `ageLabel` («сьогодні» / «3 дні»).
8. **Сторінка `/ui-kit`** (`src/app/ui-kit/page.tsx` + `views/uiKit`): усі компоненти, усі варіанти й стани, перемикач теми; доступна лише в dev (`notFound()` у production).
9. `prefers-reduced-motion` — глобальне правило з прототипу (рядок 366).

## Acceptance criteria і тест-кейси
- **AC-1** Токени обох тем збігаються з `tokens.css`.
  - [U] парсинг `globals.css` і `tokens.css`: однаковий набір змінних і значень для dark/light.
- **AC-2** `getHeat` повертає правильний рівень для всіх 7 випадків і меж.
  - [U] done (будь-який) → done; dueAt через 20 год → alarm; dueAt через 30 год, high, 0 днів → fresh; low 10 днів → calm; high 2/3/5/7 днів → fresh/warm/hot/fire; medium 3 і 8 днів → warm; medium 2 дні → fresh; done з dueAt у минулому → done.
- **AC-3** `plural`, `ageLabel`, `formatDate` коректні.
  - [U] 1 день, 2 дні, 5 днів, 11 днів, 21 день, 0 → «сьогодні»; дата з нулями в годинах.
- **AC-4** Тема: dark за замовчуванням, зберігається, без мерехтіння.
  - [E] перший візит → `data-theme="dark"`; клік → light; reload → light одразу в першому кадрі (перевірка атрибута до гідратації).
- **AC-5** Компоненти мають усі варіанти і доступні.
  - [U] (Testing Library) StatusBadge рендерить 3 підписи; HeatBadge має `aria-label` і tooltip по фокусу; AgentStepList має sr-текст стану; кнопки-іконки мають `aria-label`.
- **AC-6** `/ui-kit` показує всі компоненти в обох темах; у production — 404.
  - [E] `/ui-kit` містить секції Button, Badges, Heat, TaskRow, Agent, EmptyState, Dialog; [U] page з `NODE_ENV=production` викликає `notFound`.
- **AC-7** Адаптив і контраст.
  - [M] `/design-review` 375 / 768 / 1280 обидві теми: без горизонтального скролу, AA контраст, `TaskRow` стає карткою < 1024.
- **AC-8** `prefers-reduced-motion` вимикає анімації.
  - [E] `page.emulateMedia({ reducedMotion: "reduce" })` → `animation-duration` ≈ 1ms на HeatBadge fire.
