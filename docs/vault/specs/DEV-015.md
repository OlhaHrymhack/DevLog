# DEV-015 — Конфігуровані ліміти агентів і безпечний dev-smoke

**Tier:** визначить `classify`; очікується strong (security = 2, integrations = 2); зниження — лише явним `factory override` за рішенням користувачки · **Залежить:** DEV-008 (змерджений в `stage`) · **Агенти:** стандарт
**Покриття ТЗ:** R-11 (live перевіряється безпечно), R-12 · TC-28 (live-smoke) з [[product]]; продовжує [[specs/DEV-008]] і D-029

## Мета
Дати змогу один раз безпечно перевірити live-інтеграцію з OpenAI з жорсткими обмеженнями вартості, не змінюючи продуктових значень за замовчуванням. Рішення користувачки 2026-11-22: ліміти конфігуровані (за замовчуванням 8 викликів і 2048 токенів, як у D-029), а smoke виставляє 4 виклики і 400 токенів.

## Скоуп
**Входить:**
1. **Конфігуровані ліміти** (серверний env, Zod у `shared/config/env.ts`): `AGENT_MAX_STEPS` — ціле 1…8, default 8; `OPENAI_MAX_OUTPUT_TOKENS` — ціле 64…2048, default 2048. Значення поза діапазоном → помилка старту з назвою змінної. Верхні межі збігаються з D-029, тож бюджет ≤ 16 384 токенів output на запуск не зростає.
2. **Проводка:** `createAgentRoute` передає в `runAgent` `maxSteps = min(deps.maxSteps ?? env.AGENT_MAX_STEPS, MAX_AGENT_STEPS)`; `selectModelClient`/`createOpenAIClient` отримують `maxOutputTokens`. `maxRetries: 0` лишається. Ліміти з env пишуться в info-лог запуску (числа, не секрети).
3. **Dev-only маршрут** `POST /api/dev/agent-smoke` (Node runtime, `force-dynamic`): мінімальний агент зі справжніми read-tools над локальною БД. Захист, усе перевіряється до виклику моделі: `404` у production і коли не задано `AI_SMOKE=1`; `403` якщо хост не `localhost`/`127.0.0.1` або `Sec-Fetch-Site: cross-site`; `415` якщо `Content-Type` не `application/json`; `409 AI_NOT_LIVE` у demo-режимі (smoke без ключа безглуздий). Ліміти маршруту — `min(env, 4 виклики)` і `min(env, 400 токенів)`. Відповідь — NDJSON-події (як у DEV-008): без ключа, промптів і сирих даних задач.
4. **Скрипт `npm run smoke:ai`** (`scripts/aiSmoke.mjs`, без залежностей): вимагає інтерактивного підтвердження («Це платний запит, до 4 викликів × 400 токенів. Введіть yes»), шле запит на localhost і друкує лише метрики (статус, кількість викликів, типи кроків, код помилки). Без ключа й тіл відповідей; код 2, якщо сервер не запущено.
5. `.env.example`: нові змінні (порожні/закоментовані значення), `AI_SMOKE` — з попередженням про вартість.
**Не входить:** маршрути агентів A–D (DEV-009…012), CSRF-захист і ліміт тіла для решти маршрутів (окрема задача, зачіпає `POST /api/tasks`), автоматичний live-прогін у CI, бюджет на боці провайдера (налаштовує користувачка в дашборді OpenAI).

## Контракти
- Env: `AGENT_MAX_STEPS`, `OPENAI_MAX_OUTPUT_TOKENS`, `AI_SMOKE` (`"1"` вмикає маршрут). Ключ береться лише з серверного env і не логується.
- Помилки маршруту — єдиний формат `{ error: { code, message, details? } }` (`NOT_FOUND`, `FORBIDDEN`, `UNSUPPORTED_MEDIA_TYPE`, `AI_NOT_LIVE`).
- Фабрика маршруту приймає залежності (`getEnv`, `createClient`, `now`), як `createAgentRoute`, щоб тести не використовували мережу.

## Acceptance criteria і тест-кейси
- **AC-1** Ліміти конфігуруються й валідуються.
  - [U] default 8/2048; `AGENT_MAX_STEPS=4`, `OPENAI_MAX_OUTPUT_TOKENS=400` приймаються; 0, 9, 4096, нечислове → помилка з назвою змінної.
- **AC-2** `AGENT_MAX_STEPS` обмежує цикл.
  - [U] із 4: після 4 викликів без результату — fallback `stepLimit`; значення більше за `MAX_AGENT_STEPS` не перевищує 8.
- **AC-3** `OPENAI_MAX_OUTPUT_TOKENS` потрапляє в запит.
  - [U] на підміненому `create` з 400 → `max_completion_tokens: 400`; без значення 2048; `maxRetries: 0` лишається.
- **AC-4** Захист smoke-маршруту.
  - [U/I] production → 404; без `AI_SMOKE=1` → 404; чужий хост або cross-site → 403; не JSON → 415; demo → 409; жоден з цих випадків не викликає модель (лічильник викликів = 0).
- **AC-5** Smoke-запуск обмежений і детермінований у тесті.
  - [I] з `ScriptedClient`, що імітує live: запит до моделі має ліміт 400, не більше 4 викликів, рівно одна фінальна подія, NDJSON у порядку.
- **AC-6** Ключ і чутливі дані не витікають.
  - [U] маркер-ключ відсутній у тілі відповіді, заголовках і логах усіх гілок; промпт і дані задач — теж.
- **AC-7** Скрипт smoke безпечний.
  - [U] без підтвердження не робить запиту; вивід містить лише дозволені поля; сервер недоступний → код 2. [M] реальний запуск виконує користувачка (TC-28), вивід — у evidence.
- **AC-8** Документація й рішення.
  - [M] `.env.example` повний, запис у `decisions.md` (нове D-0xx), посилання з README (DEV-013).

## Ризики
- Занадто малий `OPENAI_MAX_OUTPUT_TOKENS` обрізає результат агента (`max_tokens` → fallback): мінімум 64 дозволений лише для smoke, у README попередити.
- `AI_SMOKE=1` залишений увімкненим на спільній машині дає платні виклики: захист — localhost, інтерактивне підтвердження в скрипті, 404 у production.
- Реакція strict-режиму OpenAI на схеми підтверджується лише цим smoke; результат фіксується в evidence.
