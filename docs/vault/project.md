# DevLog — стабільний контекст

**Що це:** трекер задач для інженерної команди з вбудованими AI-агентами (пріоритизація, декомпозиція, статус-апдейти, власна ідея). Тестове завдання Full-Stack AI-first.

**Що оцінюють:** природність роботи з coding agent, справжня агентність in-product функцій (кілька кроків, tools, валідація output), якість коду, продуктове мислення, чесність README/AGENT_LOG.
